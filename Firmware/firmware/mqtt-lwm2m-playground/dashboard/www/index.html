How latency is measured

    
    
      
  • MQTT QoS 1: PUBLISH → PUBACK. QoS 2: PUBLISH → PUBCOMP. QoS 0 has no ack: the device sends a PINGREQ right after the PUBLISH; the broker reads the TCP stream in order, so its PINGRESP proves it received the PUBLISH.
    • 
      
  • LwM2M: CON → ACK. Wakaama sends notifications NON by default; the playground marks them CON (allowed by RFC 7641) and retransmits like CoAP would, so delivery and latency can be measured. Choose NON to see the default behaviour (latency then shows "not measured").
    • 
      
  • Percentiles use the nearest-rank method over successful messages. Failed messages count against success rate and never get a latency.
